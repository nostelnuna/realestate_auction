# 한국 부동산 시크릿 경매 (`realestate_auction_server`)

1~35인이 실제 한국에 존재하는 아파트 및 주상복합건물 90곳(매 판 랜덤 45곳 출품)을 두고 벌이는 개인전 블라인드 경매 웹 보드게임입니다.

## 주요 규칙
- **지원 인원**: 1~35명 (초기 자금 50억 원, 0.1억 원 단위 입찰, 입찰 70초 · 결과 대기 30초(15라운드))
- **라운드당 3개 매물 중 1곳만 입찰**: 매 라운드 공개되는 3개 매물 중 딱 1곳을 선택해 비밀 입찰합니다.
- **시크릿(비공개) 룰**: 3개 매물 중 **가장 높은 금액으로 낙찰된 1개 건물**은 낙찰자와 낙찰가가 모두 비공개(`🔒 SECRET`) 처리되어, 다음 라운드 자금 추론 심리전이 펼쳐집니다.
- **최종 정산**: 모든 라운드 종료 후 잔여 현금과 낙찰받은 부동산의 최종 평가액을 합산해 1위~N위 순위를 공개합니다.

## Render.com 배포 방법
1. GitHub 저장소에 이 폴더의 파일들을 업로드합니다.
2. Render.com에서 **New Web Service** 생성 후 저장소를 연결합니다.
3. **Build Command**: `npm install` / **Start Command**: `npm start`
4. 기본 관리자 PIN은 `2146`입니다 (`ADMIN_PIN` 환경변수로 변경 가능).
